# CROSSFIRE Observer Setup

## Exploding's Simple Setup
* Download CrossfireObserver.cfg and place it into your CS2 cfg folder
  > _Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg_
* Launch MyHUD and go through first time setup if needed
  > Use login info located in the Staff Schedule sheet.

  > Double check that settings are correct -> [MyHUD Configuration Settings](https://github.com/Expdotdotdot/Crossfire-Observer-Information/blob/7b4d58d0233ebceae39078e9925d6943e9468cf1/docs/MyHUD%20Config.md)

  > Remember to logout after finished
* Launch game using [HLAE](https://github.com/advancedfx/advancedfx)
  > Read HLAE documentation if unsure how to launch
* Before entering server type `exec CrossfireObserver` into the console
* Join server using IP provided by admin team
  > Take care not to leak IP
* After all 10 players have joined the server type `exec sync` in console to sync/correct player names in-game
* Start observing!!!
